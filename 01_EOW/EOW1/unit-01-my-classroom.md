# EOW1 Unit 1: My Classroom

## Official Scope

| Field | Content |
|---|---|
| Theme | My Classroom |
| Goals | Name things in the classroom; talk about things in the classroom; say the color and number of things. |
| Vocabulary 1 | clock, computer, crayon, map, paper, pen, pencil |
| Vocabulary 2 | book, chair, desk, eraser, picture |
| Vocabulary Strategy | Alphabetical order |
| Grammar 1 | **Be Verb: Is** — `Is it a/an ...?`; `Yes, it is.`／`No, it isn’t.`; `It’s ...` |
| Grammar 2 | **What, What Color, and How Many** — `What is it?`; `What color is it?`; `How many ...?` |
| Reading | Drawing and Writing |
| Reading Strategy | Compare and contrast |
| Value | Work hard in school. |

## Generation Boundaries

- Do not introduce non-classroom nouns unless needed for instructions.
- Keep number/color questions simple.
- If creating worksheets, prefer classroom-object recognition, matching, counting, and short Q&A.
