# EOW1 Unit 2: My World

## Official Scope

| Field | Content |
|---|---|
| Theme | My World |
| Goals | Name things in nature; talk about natural things; ask where things are. |
| Vocabulary 1 | bird, butterfly, river, rock, sky, sun, tree |
| Vocabulary 2 | bush, cloud, flower, moon, star |
| Vocabulary Strategy | Ending `-s` |
| Grammar 1 | **Be Verbs: Is and Are** — `What is it?`／`What are they?`; `It’s ...`／`They’re ...` |
| Grammar 2 | **Where** — `Where is ...?`／`Where are ...?`; locations with `in` and `on` |
| Reading | Rainbows |
| Reading Strategy | Use visuals to support comprehension |
| Value | Enjoy nature. |

## Generation Boundaries

- Nature vocabulary should stay inside the official list.
- Grammar can practice `is/are`, `Where is/are...?`, `in`, and `on`.
- Avoid adding extra prepositions unless the worksheet is explicitly a review.
