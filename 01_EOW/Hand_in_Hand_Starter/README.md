# Hand in Hand Starter

This folder contains the scope and sequence for the **Hand in Hand Starter** textbook, which serves as the foundational curriculum reference for PAS Starter-level students.

## Role in PAS Curriculum

Hand in Hand Starter is the primary textbook for first-year English learners at PAS. While EOW (Explore Our World) covers Levels 1–4, the Starter level uses Hand in Hand as its core textbook. Summer Camp Starter projects draw vocabulary, sentence patterns, and conversation topics directly from this textbook.

## e-reading.now (2026-09-29)

All 12 units are live on e-reading.now: Hand in Hand (series 6) › Starter (folder 30115) › Unit 1–12 (folders 30116–30127). Each unit has vocabulary cards (textbook audio, transparent pictures, no Chinese), shadowing sets for conversation / sentences / English Sounds / chant / story (textbook audio, line by line), one Listen & Pick game, and a `listening_vocab` quest. Songs, the Ditto & Fluffy comic and the listening-test track are not used.
