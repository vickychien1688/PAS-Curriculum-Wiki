# Hand in Hand Starter

This folder contains the scope and sequence for the **Hand in Hand Starter** textbook, which serves as the foundational curriculum reference for PAS Starter-level students.

## Role in PAS Curriculum

Hand in Hand Starter is the primary textbook for first-year English learners at PAS. While EOW (Everyone's a Writer) covers Levels 1–4, the Starter level uses Hand in Hand as its core textbook. Summer Camp Starter projects draw vocabulary, sentence patterns, and conversation topics directly from this textbook.
